# نصار الحميري — بوت الأرقام الافتراضية
النسخة تحتوي على بوت Telegram + محفظة + إيداعات + طلبات أرقام + إدارة موردين ومنتجات + مستخدمين + أزرار + قاعدة بيانات + لوحة ويب.

كلمة مرور لوحة التحكم: `xH4yBmFodX_7tw`

التشغيل:
`pip install -r requirements.txt`
ثم:
`python run.py`

الموردون:
يجب أن يكون لدى الموقع الخارجي API رسمي ومصرح به. لا يمكن جعل أي موقع عشوائي موردًا تلقائيًا بمجرد وضع رابطه، لأن لكل خدمة API وآلية مصادقة مختلفة.

أمان:
التوكن الذي طلبت إضافته موجود في .env. بما أنه ظهر في المحادثة، يفضّل تغييره من BotFather قبل استخدام البوت فعليًا.
